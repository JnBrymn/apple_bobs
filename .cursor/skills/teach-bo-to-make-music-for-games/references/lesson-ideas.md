# Lesson ideas for Bo

Ordered basics on the way to **keyboard → MIDI file → music in his game**. Not a fixed curriculum — use to suggest what he might try next. His name is **Bo** (B-O).

Possible learning paths live here; [records.md](records.md) shows what he has actually done.

**Bo’s profile:** comfortable with **piano**; **beats** less familiar but **important for games** (action, menus, tension). Offer piano/melody paths often; don’t skip beat/pad lessons long-term.

---

## Quick win (north star)

- Hear the keyboard in **one computer app** (not only the built-in speaker).
- **Record** a short tune.
- **Save a file** — for games, usually **`.mid`** (MIDI), not only MP3/WAV.
- **Play it back** from one of his `index.html` games (even a simple Play button counts).

---

## 1. Ideas in his head (concepts)

- MIDI = instructions for notes; audio file = finished listening.
- Keyboard alone vs keyboard controlling the computer.
- Game music can start small and imperfect.

---

## 2. Keyboard + Windows (hardware)

- USB plug-in; USB vs battery power.
- Internal sounds on vs off (who makes the sound).
- “Keyboard speaker or computer app?”
- Volume: keyboard, app, Windows.
- Pads ≈ drums; keys ≈ melody (rough rule).

---

## 3. What each program is for

| Program | Role |
|---------|------|
| inMusic Software Center | Download/install — parent tool |
| **MPC Beats** | Installed; **beats + export**; melody on instrument tracks (beat-first UI) |
| **LMMS** | **Piano/melody-first**; install when ready; same `.mid` → `game-midi/` |
| Electric / Hype / Essential Keyboards (AIR) | Jam with cool sounds; not usually where game MIDI is exported |

**Recording to a file:** **MPC Beats** or **LMMS** (not AIR alone). **Piano tunes →** LMMS when installed, or melodic track in MPC. **Game drums/beats →** MPC pads/expansions (worth learning even if piano is easier for Bo).

---

## 4. MPC Beats basics

- MIDI input = MPK in Preferences.
- Instrument track so keys make sound.
- Record → stop → listen back.
- Save project.
- **Export `.mid`** (unlock for games).
- Later: export WAV/MP3, piano roll, more tracks.

---

## 5. AIR plugins (Electric, Hype, Essential Keyboards)

- Open app; keys trigger a preset.
- Change preset; fix MIDI input in Settings if silent.
- “Jam here; save for games in MPC Beats.”
- Pick a favorite sound for later.

---

## 6. Simple music-making

- Short loops (4–8 bars).
- Name the tune.
- **Melody on keys** (piano comfort zone).
- **Beats on pads** — simpler patterns for game feel (menu, mining, boss); teach even if he prefers piano.
- Loud/soft keys; fast/slow (tempo) when ready.
- Fix mistakes by re-recording or (later) piano roll in LMMS / MPC.

---

## 7. File → game

- Know where `.mid` lives on the PC.
- Hear the file outside the game first.
- Wire one song into one game folder.
- Match mood to scene (mining, boss, menu).

---

## 8. Troubleshooting (as problems appear)

- Sound only from keyboard.
- App open, no sound.
- Recorded but no file → export/save.
- File won’t play in game → format/path; test outside game.

---

## 9. Later (after quick win)

- Piano roll, quantize, pad drums, sample packs.
- Multiple tracks; effects.
- Shared music folder across games.

---

## Chapter order (where it lives)

**Do not use a fixed list here for suggestions.** Use **[records.md → Chapter path](records.md#chapter-path)** — that is the live ordered list for Bo.

**Starter chapters** (only until he has clearly **mastered** all of these — check accomplishments in records):

1. One note in MPC Beats from the keyboard.
2. Record a few bars; play back.
3. Export `.mid` (parent may help find menu once).
4. Play `.mid` in one game.
5. Try one AIR app for fun.
6. Second song or pads.

**When the starter path is mastered:** read accomplishments + his games + §9 “Later” above. Write a **new 4–8 item chapter list** in records **Chapter path**, replacing the starter list. Tailor it (e.g. boss music for Perfect Mine, pad drums, two tracks). Do not leave the starter list in records once replaced.
